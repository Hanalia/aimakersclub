## *당신의 MCP 서버로 아마존 19만 달러 해커톤에 도전하세요!* 핵심 요약

- 올해 MCP 서버를 만들었다면, Amazon Alexa Plus용 개발의 대부분을 이미 완료한 것이나 다름없음
- MCP는 Amazon이 Alexa Plus 외부 서비스 연동 표준으로 채택한 프로토콜임
- MCP 서버는 최소한의 수정만으로 Alexa Plus와 바로 연동 가능
- Amazon Developer가 MCP/Agent-Skill 기반의 글로벌 해커톤을 개최 중임
- 해커톤 카테고리는 Alexa Plus, Fire TV, Ring, B 총 4가지
- Alexa Plus 부문 참가자는 MCP 서버 또는 Agent-Skill을 제작해 인티그레이션을 시연해야 함
- Echo 기기가 없어도, Agentic 툴을 이용해 Web-App에서 Alexa Plus 경험을 100% 시뮬레이션 가능
- 전체 해커톤 상금 및 AWS 크레딧 규모는 19만 달러, Alexa Plus 1등에겐 상금 2.5만 달러 및 1.5만 달러 AWS 크레딧 지급
- 개인·팀 단위 누구나 참가 가능, 경험/경력 무관
- 툴 관련 피드백은 아마존 제품팀에 직접 전달됨
- 신청은 즉시 가능하며, 제출 마감일은 10월 23일임
- 신규 학습 필요 없이 기존 MCP 서버 작업물로 바로 참가할 수 있다는 점이 큰 장점임

## 세부 요약 - 주제별 정리

### MCP 서버 개발 경험이 있으면 Alexa Plus 연동은 거의 완료된 것과 같음

- 올해 이미 MCP 서버를 작업했다면, Alexa Plus 개발의 상당 부분을 마친 셈임
- Alexa Plus는 MCP 서버와의 외부 서비스 연동 표준으로 MCP를 선정함
- MCP 서버는 최신 사양(스펙) 기준 스트리머블 HTTP 기반임
- 기존 MCP 서버도 아주 적은 수정만으로 바로 Alexa Plus와 연동하여 작동함

### MCP 프로토콜 도입으로 Alexa Plus가 외부 도구 연계를 표준화함

- Amazon이 Alexa Plus용 외부 서비스 연결 프로토콜로 MCP(Standard for connecting external services to Alexa Plus)를 공식화함
- Alexa Plus는 흥미로운 점으로, 도구들은 개발자가 제공하고, Alexa Plus가 UI(대화, 화면 및 음성 등)를 담당하는 구조임
- MCP 서버는 외부 도구(툴)를 빠르고 손쉽게 Alexa Plus에 붙일 수 있게 함

### 글로벌 해커톤 개최 및 참가 부문 구성

- Amazon Developer가 MCP 및 Agent-Skill 통합과 관련된 해커톤을 전세계적으로 개최함
- 해커톤은 총 4개 카테고리: Alexa Plus, Fire TV, Ring, B로 구분됨
- 특히 Alexa Plus 카테고리에선 MCP 서버 또는 Agent-Skill을 제작 및 시연해야 함
- 참가자들은 MCP 서버와 Alexa Plus 인티그레이션을 직접 보여줘야 함

### Echo 없이도 Web-App 과 Agentic 툴로 Alexa Plus 경험 시연 가능

- 실제 Echo 기기가 없어도, 필요한 Alexa Plus 경험은 온라인 Web-App 및 기존 Agentic 툴을 통해 모두 시뮬레이션 가능함
- 참가자가 이미 사용하던 개발 도구 그대로 활용해, Alexa Plus 환경을 가상으로 구현할 수 있음

### 전체 해커톤 상금 및 부상 내역이 크고 매력적임

- 해커톤 총 상금규모 및 AWS 크레딧은 합계 19만 달러(약 2.5억 원)에 달함
- Alexa Plus 카테고리 1등에겐 현금 25,000달러, AWS 크레딧 15,000달러 지급
- 모든 카테고리 별 수상자도 상금과 AWS 크레딧을 제공받음

### 참가 방식이 자유롭고, 경험 유무에 상관없이 누구나 도전할 수 있음

- 팀 단위 또는 개인 참가 모두 허용됨
- 전문 개발자 경험이 없어도 누구나 도전 가능함
- 해커톤에 대한 진입장벽이 매우 낮음

### 사용자 피드백이 아마존 실제 제품팀에 직접 전달되는 기회임

- 해커톤 참여 중 제공되는 도구 관련 피드백은 아마존 제품팀에게 곧장 전달됨
- 참가 경험이 곧바로 제품 개발에 반영될 수 있는 실질적인 창구임

### 접수 및 제출 일정, 참가 준비에 관한 안내 사항 정리

- 해커톤 제출(Submission)은 영상 게시 시점부터 바로 가능함
- 마감일은 10월 23일까지로 넉넉한 준비 기간 제공됨
- 참가 신청 링크는 영상 설명란에 포함되어 안내됨

### 새로 배울 것이 거의 없으며 기존 작업물을 그대로 활용 가능함

- 기존에 MCP 서버를 이미 구축했다면, 추가 학습 없이 그대로 제출해도 무방함
- 해커톤 참가를 위해 특별히 "새로운 것"을 배울 필요가 없음
- 실질적으로 기존 프로젝트 결과물을 접목해 실전 서비스로 진출하는 기회임

### 부상과 인지도를 동시에 얻을 수 있는 특별한 기회임

- 본인 또는 팀의 MCP 서버를, Amazon Alexa Plus와 같은 대중 제품 플랫폼에 올릴 수 있는 드문 기회
- 해커톤 성과물은 실사용 환경(예: 일반인의 주방)에 적용될 수 있음
- 실제 서비스화, 노출, 보상, 네트워킹 등 다양한 혜택 기대 가능함
