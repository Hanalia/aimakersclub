## *이 스킬로 Claude 코드가 전문가급 영상 편집자가 된다 (무료로 공개)* 핵심 요약

- 영상 제작자는 Claude 기반 코드 에이전트로 작동하는 자신의 ‘AI 세컨드 브레인’이 최근 모든 동영상을 편집해왔으며, 이를 가능하게 해준 핵심 *edit video skill*을 오픈소스로 무료 공개함을 알림
- 이 스킬은 기존 코딩 에이전트가 영상 편집 시 겪는 마지막 10%의 반복적이고 미세한 작업 부담을 획기적으로 낮추어, 손수 직접 편집할 때 드는 시간을 대폭 절감함
- 단순한 명령(예: “이 비디오를 편집해줘”와 파일 경로 제공)만으로도 복잡하고 어지러운 원본 폴더 내에서 클립을 선별·조합·컷 편집·애니메이션 및 전환 삽입·최종 출력 등 모든 프로세스를 자동화함
- 필수 5단계(전사 → 리테이크 제거 → 컷 편집 → 클립 조립 → 다듬기 및 내보내기)와, 영상 종류별로 추가되는 커스텀 단계(쇼츠/화면+얼굴버블/애니메이션 등)를 직접 조합하여 유연하게 적용 가능
- 각 단계마다 AI가 제대로 이해하지 못하는 특수 작업(예: 타임스탬프 추출, 무의미한 공간 감지 등)은 별도의 스크립트로 처리하여 신뢰도와 반복가능성을 크게 향상시킴
- 오픈라우터(OpenRouter) 기반 멀티모달 모델을 통한 고급 파이프라인에서는 리뷰, 음성 클론, 썸네일 생성 등도 지원하며, 영상 전체를 $2.71(약 3,700원) 내외로 자동 편집
- 직접 구현한 샘플 케이스로, 음성 미국, 미세한 삐끗거림 교정, 자연스러운 장면 전환, 단어 잘못 발화(“70%” → “75%”) 음성 교체, 썸네일·쇼츠 생성 등이 실제로 작동하는 모습을 단계별·비포/애프터 영상과 함께 시연
- 전체 구조를 사용자가 쉽게 커스터마이즈할 수 있도록, 에이전트가 질문하거나 lessons.mmd·brand.json 등 참조 파일을 수정하며 자신만의 규칙 및 브랜드 색상을 적용 가능하게 설계
- 모든 코드는 깃허브 저장소에 공개하며, 영상 편집 툴이 아닌 “AI 에이전트용 스킬”이기 때문에 다양한 에이전트(예: Hermes, OpenClaw, Rockbot 등)와 연동 사용 가능
- 썸네일 디테일, 짧은 영상(쇼츠), 화면+얼굴버블, 애니메이션 적용 등 교육/프레젠테이션 외에도 다양한 컨텐츠 편집에 충분히 활용할 수 있다고 강조

## 세부 요약 - 주제별 정리

### Claude 기반 AI 세컨드 브레인과 edit video skill이 영상 전체 편집을 완전 자동화함

- 영상을 보는 시청자는 실제로 이 edit video skill을 사용해 편집된 결과물을 직접 체험 중임
- 제작자는 수개월간 이 스킬의 완성도를 높이기 위해 반복적으로 개선, 세 번째자도 쉽게 쓸 수 있도록 배포
- gitHub상의 "Cole Medin skills" 레포지토리에서 edit video skill을 무료·오픈소스로 공유
- 단일 스킬임에도, 애니메이션, 타임스탬프 전사, 클립 정제, 자동 조합 등 복잡한 작업을 전자동으로 처리함
- 기존에는 원본 파일을 에이전트에 던져넣고 “알아서 편집해”라고만 했을 때, 마지막 10% 반복 수정을 사람이 일일이 해야 했다면, 이 스킬이 해당 수고를 근본적으로 해소
- 에이전트 스킬 구조를 통해 반복 개선이 자동화되어, 지속적으로 고품질 편집 결과를 도출

### 영상 편집 자동화의 ‘필수 5단계’가 스크립트화되어 높은 신뢰도를 보장함

- 스킬이 지시하는 편집 파이프라인: ① 전사(자막·타임스탬프 추출) → ② 리테이크/NG 컷·불필요한 반복·숨 고르기 등 삭제 → ③ 클립 자르기(컷팅) → ④ 클립 조립(스티칭) → ⑤ 다듬기(전환, 애니메이션 등 추가) 및 내보내기
- 각 단계는 별도의 파이썬 스크립트로 작동, 예측가능성과 반복가능성이 큼
- 예시: 전사 단계에서는 음성→텍스트 변환과 동시에 각 단어의 타임스탬프를 추출, 반복적·불필요 리테이크 구간을 자동 인식하여 제거
- 컷 편집은 음성 중복·침묵·데드에어 등 소요 구간을 텍스트와 비교하여 컷팅 결정
- 조립 단계 이후에는 검증 스크립트가 실제로 올바른 구간에서 컷이 이루어졌는지 “재전사”하여 word-by-word diff 수행
- 마지막 단계에서는 애니메이션, 전환 효과, 기타 사용자가 지시한 시각효과를 삽입 후 최종 영상 출력

### 다양한 영상 유형별로 단계 조합을 유동적으로 구성할 수 있도록 설계됨

- 단순 토킹헤드(1인 발표), 화면+얼굴 버블, 애니메이션 삽입, 쇼츠, 교육/강의 등 여러 유형을 지원
- skill 최상단의 표(table)에 컨텐츠 유형별로 필수 및 선택 단계가 정리되어 있음
- 명확히 지시하지 않으면 스킬이 사용자에게 추가 정보를 요청함(예: 애니메이션 추가 여부, 쇼츠 생성 등)
- 표의 단계(0: 간단한 설명/지시 → 1~5: 공통 5단계 → 6 이후: 유형별 커스텀 단계) 기반으로, 필요시 새 유형/새 단계 추가 및 삭제도 자유로움
- 오픈소스이기에 사용자가 직접 표와 단계 정의 구조를 수정·확장 가능

### 사용자는 브랜드 컬러, 애니메이션 스타일, 커스텀 규칙 등을 자유롭게 적용할 수 있음

- 스킬은 lessons.mmd(누적된 시행착오 & 시행착오별 간단 규칙 기록)와 brand.json(애니메이션용 색상 등) 파일을 통해 사용자의 커스터마이징을 지원
- 반복적 에러나, LLM이 자주 실수하는 포인트를 natural language로 기록하여 점진적 개선
- 신입 사용자를 위해, 에이전트가 스킬 내용을 스스로 분석하고 “어떤 것을 커스터마이즈할지” 직접 안내해줄 수 있도록 구조화
- 개인 스타일, 작업 흐름, 선호 스타일, 브랜드 일관성에 맞추어 다양한 요소 커스터마이즈 추천

### 멀티모달 모델(OpenRouter) 파이프라인이 복잡한 작업과 품질 향상을 동시에 보장함

- 기본 파이프라인 단독으로도 대부분의 작업(전사, 컷팅, 조립, 다듬기, 출력)이 전부 로컬 환경(Whisper 등)에서 가능
- 그러나 OpenRouter 멀티모달 파이프라인을 통해 고난이도 작업 가능: 영상 자체 인식, 음성 클론, 이미지(썸네일) 생성 등
- OpenRouter API키 하나만 준비하면, Gemini, Fish Audio 2.1 Pro, 11Labs, GPT Image 2, Cream, Flux 등 다양한 모델 자유롭게 조합 가능
- 실제로 Fable 5.2 영상 전체 자동 편집 비용은 $2.71로 매우 저렴함
- 사용자가 “full pipeline”을 요청하면 에이전트가 알아서 OpenRouter 경로로 고급 모델을 사용하도록 설정

### 스킬이 감지·교정하는 실제 예시를 일정별, 전후 비교로 보여줌

- 음성/영상 미세 문제(작은 말실수, 발음 삐끗, 구간 뒤틀림, 샷 전환 시 순간 끊김 등)까지 정확히 감지 후 자동 수정
- 실제로 “70%”라고 잘못 말한 부분을, Fish Audio 2.1 Pro를 통한 음성 클론+교정으로 “75%”로 바꿔, 자연스럽게 음성 교체
- 초기 컷 편집 결과 LLM이 구간 경계 미스→자동 self-iteration 반복으로 문제 감지 후 정확하게 재조립
- 장면 전환도 일반적 영상 편집 툴 못지않은 부드러움 구현: 효과음·애니메이션까지 적용

### 썸네일, 쇼츠 등 영상에 필요한 부가 리소스 생성도 한번에 처리함

- 썸네일은 LLM을 통해 불완전하더라도 초안 생성(cell: Gemini 3 Pro, GPT image 2, Cream, Flux 등 각종 모델 활용); 완성 썸네일은 직접 다듬는 방식
- 이 과정 역시 값싸고 다양한 iteration 반복이 가능, 유튜브 업로드용 영상은 모두 썸네일 자동 초안 생성
- 장시간 영상→쇼츠 자동 추출(하이라이트 컷, 애니메이션 삽입, 비포맷 전환 등)을 통해 컨텐츠 확장
- 실제로 Fable 5.2 영상에서 35초짜리 쇼츠 자동 생성, 애니메이션+장면전환까지 완벽하게 처리

### 코딩 에이전트와의 연동 구조·동작 방식도 직관적으로 안내됨

- Hermes, OpenClaw, Rockbot 등 다양한 코드 에이전트와 바로 연동 가능
- 사용자는 단순히 구체적 요구(예: 어떤 유형 영상, 어떤 스타일의 편집, 어떤 쇼츠 생성 등)와 파일 경로만 제공
- 나머지는 에이전트와 연결된 스킬이 상황별로 최적화된 스크립트·단계 조합을 실행
- 자잘한 실수·디테일 미스가 발생하면, lessons.mmd에 직접 규칙 추가하며 반복 개선

### 영상 편집 결과물이 업로드 가능한 수준의 완성도를 자동으로 달성함

- 완성 결과물은 대부분 사람이 직접 편집한 것과 비슷할 만큼 자연스럽고 부드러움
- 단, 업로드 전 최종 리뷰(마지막 미세 수정)는 여전히 권장
- 예시 영상 대부분은 edit video skill+OpenRouter 조합 결과물 그대로이며, 수작업 없이 디테일까지 처리됨

### 영상 제작자와 오픈소스 커뮤니티의 지속적 피드백·참여를 유도함

- 레포지토리 및 스킬에 대한 피드백, 문제점, 개선 아이디어를 댓글로 적극 수집할 계획임
- “Out of the box”로 쓸 수 있지만, 자신의 워크플로우에 맞게 단계·규칙을 충분히 커스터마이즈 가능함을 강조
- 더 다양한 강좌, 에이전트용 스킬 안내 영상도 곧 공개 예정이라고 예고
