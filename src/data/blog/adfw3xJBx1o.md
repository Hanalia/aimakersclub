## *은행이 자체 코딩 에이전트를 만들었다: Monzo의 Agent Chip 도입 사례* 핵심 요약

- 본 영상은 Monzo 디지털은행이 자체적으로 구축한 LLM 기반 코딩 에이전트 ‘Agent Chip’의 개발 과정과 내부 도입 효과, 아키텍처를 상세히 다룸
- Monzo는 3,000개 이상의 백엔드 서비스와 13,000개 이상의 데이터 웨어하우스 모델, 다수의 머신러닝 예측기를 운영하는 대규모 IT 인프라를 보유
- Agent Chip은 Slack 채팅에서 간단한 이모지 반응이나 멘션으로 다양한 업무 요청∙코드 리뷰∙질의처리 등을 자동화하여 ‘항상 사용할 수 있는 동료’ 개념으로 빠르게 확산
- 도입 약 6개월 만에 전체 머지 PR의 10% 이상 작성, 하루 1,800건 이상의 작업 자동화, 비즈니스 사용자까지 활용 영역 확장
- 성공 요인으로 “강력한 플랫폼 기반”을 강조하며, Monzo 고유의 경보, 모니터링, 외부 연동, 배포 자동화 등의 구축 자산이 Agent Chip의 빠른 확산·가치 창출에 핵심적 역할
- MCP 게이트웨이와 오케스트레이션 시스템 등으로 에이전트의 도구, 권한, 연결 리소스를 안전하게 통제하면서도 샌드박스 환경에서 실험 가능하도록 설계
- 코드 자동화, 인시던트 대응, 데이터 품질 모니터링, 백엔드 변동 감지 등 다양한 실제 사례 소개
- 비전문가 직원 역시 Agent Chip을 통해 더 쉽게 시스템에 기여할 수 있게 되어 조직 전반에 생산성 향상 효과
- Monzo 플랫폼은 클라우드 및 LLM 제공자에 독립적으로 설계, 다양한 모델을 용도별로 쉽게 교체 및 적용 가능
- Agent Chip은 단순한 도구가 아닌, 기업 내 AI 에이전트 활용을 위한 새로운 빌딩블럭이 되어 여러 추가 사례로 확장 중
- 결론적으로 “LLM = lots of little multipliers(수많은 가치를 증폭시키는 요소)”라는 관점에서, 자체 인프라와 통합된 AI에이전트가 조직의 복합가치를 극대화함을 강조

## 세부 요약 - 주제별 정리

### Monzo가 겪는 대규모 IT 운영의 복잡성은 코딩 에이전트 도입을 필요로 만듦

- Monzo는 금융 분야의 디지털 선도은행으로, ‘돈이 모두에게 잘 작동하게 하자’는 미션 아래 운영
- 3,000개 이상의 백엔드 서비스, 13,000개 이상의 데이터 웨어하우스 모델, 다수의 머신러닝 예측기 등 복합적이고 방대한 시스템을 관리
- 신용결정, 금융범죄 탐지, 다양한 앱·데이터 기반 서비스 등 고도화된 IT 활용
- 이러한 대규모 인프라 운영에서 발생하는 시스템 관리, 코드 리뷰, 데이터 문제 해결 등 반복∙복잡 업무가 많아 혁신적 자동화 필요성 대두

### Agent Chip은 자연스럽게 ‘조직 내 인기 동료’처럼 자리잡음

- 2026년 1월, 사내 Slack 채널에서 ‘Agent Chip’이 바이럴하게 확산됨
- 사용자들은 메시지에 특정 이모지(아이콘)로 반응하거나, 멘션을 통해 에이전트를 호출
- 코드 리뷰, 질의 응답, 아키텍처 정보 탐색 등 실제 동료처럼 다양한 업무 지원
- Linear(티켓 관리 도구) 연동으로 티켓(업무 요청)까지 자동 처리 가능
- 직원들에게 ‘언제든 요청 가능한 동료’라는 인식으로 빠르게 신뢰와 활용도 상승

### Agent Chip 도입 6개월 만에 업무 자동화 실적과 활용성이 크게 증명됨

- Agent Chip이 작성한 머지 PR(풀 리퀘스트)이 전체의 10%를 초과
- 데이터, 머신러닝, 백엔드, 앱 등의 범위에서 하루 1,800건이 넘는 업무 자동 실행
- 기술팀 외에 비즈니스 사용자의 쿼리 작성, 업무 자동화 등 실무적 확장도 가속화
- 에이전트 기반 코딩 도입 사례가 업계 화두가 되고 있음(같은 해 뉴욕 콘퍼런스 등에서 관련 언급)

### 비교우위의 성공 원인은 ‘플랫폼 기반의 미리 구축된 인프라’에 있음

- Monzo는 도입 전부터 경보(alert), 모니터링, 외부 서비스 연동, 스테이징 환경, 큐잉 추상화, 배포 자동화, 데이터베이스 추상화 등 다양한 내부 플랫폼 역량을 보유
- Agent Chip은 이러한 ‘강력한 내부 플랫폼’을 레버리지하여, 신속하고 안전한 대규모 자동화 기능을 제공할 수 있었음
- 단순히 AI 모델 성능만이 아니라, 조직별 인프라의 융합과 대응력이 자리잡힌 상태가 성공의 비결로 지목

### MCP 게이트웨이와 오케스트레이션 아키텍처가 핵심 안전장치와 확장성을 동시에 제공함

- 초기에는 로컬 코딩 에이전트 지원부터 시작해, MCP(Monzo Control Plane) 게이트웨이 구축
- MCP 서버는 내부 서비스·지식 저장소를 에이전트가 안전하게 활용할 수 있도록 인증·인가, 접근 통제
- 원격 실행 에이전트는 샌드박스 격리 영역 내에서만 작동, 회사 핵심 시스템의 안전 보장
- MCP 서버·오케스트레이션 시스템이 에이전트의 행동과 권한을 정밀하게 제어
- Monzo는 금융권 규제를 준수하기 위해 에이전트의 비결정론을 회사 인프라와 철저히 분리

### 세분화된 샌드박스 환경과 도구 세팅으로 ‘안전한 자동화’를 현실화함

- 격리 네임스페이스에서 에이전트는 각 샌드박스(pod) 안에서 구동
- 에이전트 이미지(image)로 사용 가능한 도구, 환경, 인증, 권한 범위를 구체적으로 정의
- 프록시(proxy)를 이용해 외부(예: 코드 저장소, 깃허브)와 통신하며, 허용된 데이터만 제한적으로 접근
- ‘박스 안의 박스’ 구조로, 특정 경계 내부에서는 에이전트의 자유 행동(비결정적 처리)을 허용하되, 엄격한 데이터∙액세스 통제를 유지
- MCP 서버와의 연동을 통해 정보 안전성과 데이터 자산 통합 관리가 용이함

### Agent Chip은 복수의 실제 업무 시나리오에서 고도화된 효과를 보임

- 인시던트 모드: 시스템 이상(incident) 감지 시 Agent Chip이 자동으로 채널 합류,
    - 로그, 트레이스, 서비스·코드 기록 분석,
    - 주요 원인 탐색 및 관리자에게 신호를 제공,
    - 인간 사용자가 영향 범위·지원 수준을 직접 제어 가능
- Squad 간 Q&A(Ask 채널): 부서 또는 프로젝트 단위로 백엔드ㆍ로드맵 등 질의에 자동 응답 작성,
    - 필요시 인간이 최종 확인 및 보완,
    - 정보 출처 접속 및 문서 참고
- 데이터 품질 경보: 데이터 오류가 발생할 경우 Agent Chip이 자동 감지, 근거 자료 추적 후 원인 조사
- 사전적 모니터링(프로액티브): 백엔드 변경 감지 후, 데이터 미처리 단계에서 잠재 이슈 예측 및 알림

### 비개발자 직원도 Agent Chip을 통해 시스템 기여가 용이해짐

- Slack 내 진입 장벽이 낮아져, 제품 피드백·아이디어·토론 상황에서 비전문직이 초안 코드 혹은 구축 아이디어를 쉽게 요청
- Stage(테스트) 환경에서 검증 가능한 결과물을 생성하며, 추후 엔지니어가 최종 리뷰 및 배포만 담당
- 조직 내 다양한 분야 인력이 디지털 시스템에 직접적인 영향을 주게 되어, 개발합습의 일원화 및 조직 생산성 극대화

### 자체 플랫폼 아키텍처의 유연성이 에이전트 도입 확장과 미래 경쟁력의 원천이 됨

- Agent Chip은 Monzo 내부 플랫폼의 새로운 빌딩블록 중 하나로 자리잡음
- 신규 use-case나 제품 자동화를 빠르게 내재화 가능
- 클라우드 및 LLM 모델 독립적 구조로 설계되어, 특정 LLM(예: OpenAI, Anthropic 등)에 종속되지 않고 목적에 따라 자유롭게 모델 선택 및 교체 가능
- 기능 도입 후 중단하더라도 그 효과는 지속적으로 조직에 가치를 제공하는 구조

### Agent Chip은 ‘LLM=작은 요소들의 가치 증폭’이라는 철학 아래, 조직혁신을 주도함

- Agent Chip은 단순히 한 번의 자동화 도구를 넘어, 여러 시스템 및 업무단위에서 중첩적으로 재활용될 수 있는 확장성과 합성 가능성(composability)을 보유
- 안전성, 빠른 확장, 업무 간 소통 효율, 비전문가 참여 활성화 등 다양한 복합적 효과 동시 달성
- 영상 발표자는 LLM의 의미를 “대형 언어모델”이 아닌, “lots of little multipliers(수많은 작은 가치 증폭기)”라고 재정의하며
    - 에이전트화된 업무 자동화와 그 기반 인프라가 실제 조직 생산성에 미치는 시너지를 강조
- Monzo의 Agent Chip 사례는 LLM과 플랫폼 융합으로 복잡한 대규모 기업 환경에서도 AI 에이전트가 실질적이고 변혁적인 역할을 할 수 있음을 명확히 시사
