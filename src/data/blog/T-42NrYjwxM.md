## *우리의 소형 모델이 금융 과업에서 Opus를 이겼다* 핵심 요약

- 발표자는 Ramp의 Applied AI 팀의 Alexander Shevchenko로, 빠르게 발전하는 LLM 모델 환경에서 실질적 가치 창출 경험과 교훈을 공유함
- Ramp 내에서 LLM 활용 사례는 1년간 123% 증가했고, 주요 기능들의 토큰 사용량도 증가했으나, 최신 모델 도입으로 단위 경제성은 향상되어 비용이 낮아짐
- 연구와 실험을 통한 자체 적용이 필수임을 강조하며, 이유로 “기다림”보다 적극적인 연구·개발의 실익을 2023~2026 AI 에이전트 발전상 비교로 설명함
- Ramp Labs에서는 ①금융 특화 Q&A 모델 공동 개발, ②KV 캐시/카트리지 기반 사전 문맥 구성, ③대규모 병렬 에이전트 기반 자동화 보안 점검 등 세 가지 구체 프로젝트 사례를 제시
- Prime Intellect와 협력해 Qwen 3.5 기반 금융 Q&A 모델을 후학습(post-train)하여 당시 최첨단 Opus 4.6보다 높은 정답률과 빠른 응답속도 달성함
- KV 캐시 “카트리지” 기법으로 월말 결산 등 반복 작업의 콘텍스트를 최대 20~30배까지 압축하여 금융 전문가의 업무 효율화 실현
- 1만개 병렬 에이전트로 Ramp 전사를 자동 침투테스트, LLM 기반 표적 중복 제거 및 취약점 자동 검증으로 7건의 고위험 취약점 탐지
- 직접 연구한 기술들은 실제 Ramp의 토큰 소비 관리, 지능형 라우터(예:Nvidia Switchyard) 등 제품에도 적용되어 고객 관점 시간·비용 절감에 기여
- 라우팅, 오픈웨이트 모델 활용 등 추가 전략으로 Frontier 모델 대비 5배 저렴한 비용과 유사한 성능 확보
- 연구 결과를 Ramp Labs 블로그에 공개하며, 포스트트레인 지식 이전, 셀프 모니터링, 의미론적 태깅 등 다양한 기법 소개

## 세부 요약 - 주제별 정리

### AI 도입 속도와 Frontier 모델 발전이 Ramp에서 LLM 연구를 필수로 만듦

- Ramp는 1년간 LLM 적용 사례가 123% 증가할 정도로 빠르게 AI를 도입하고 있음
- Frontier(최첨단) 모델의 출시 주기가 빨라지면서, 정확도는 유지한 채 비용과 속도 면에서 이득을 보고 있음
- 가장 최신 Frontier 모델을 바로 적용 가능하지만, 주어진 상황에서 “기다리기”만으로는 사업 경쟁력이 약해질 수 있다고 판단
- Ramp는 실험과 실제 적용의 교훈을 중시하여, 꾸준히 Applied Research와 Ramp Labs의 역할을 강조함

### 2023년과 2026년의 LLM 기반 에이전트 개발 여건이 극적으로 변화함

- 2023년경엔 GPT-4 등 Frontier 모델 활용 시, 에이전트 구축에 매우 엄격한 가드레일, 복잡한 프롬프트 설계가 필수였음
- LLM 내부 추론(Thinking tokens) 부재로 오류에 대한 재조정이 불가능, 동의어 변경만으로 에이전트 동작이 달라지는 등 취약점 존재
- 맥락(콘텍스트)이 너무 많으면 에이전트가 혼란을 느끼므로, 최소화 전략이 요구됨
- 그러나 “지금 움직여야 한다”는 판단 하에 Ramp Tour Guide 등 실사용 가능한 에이전트를 조기 출시함
- 2026년에는 Frontier 모델이 훨씬 개선되어, 많은 맥락(MCP, 다양한 정보)에서도 자동으로 상황을 파악해 임무 수행 가능해짐

### 금융 특화 Q&A 모델을 공동 개발해 Opus 4.6 대비 더 높은 정확도와 속도를 달성함

- 2023년 11월, Ramp Labs는 “Ramp Sheets”라는 초기 스프레드시트 에이전트를 출시
- 사용자는 Excel/스프레드시트 내 다양한 금융 시나리오(DCAF, 모델링 등)를 자동화로 요청 가능
- 초기엔 Opus 4.6 모델을 사용, 복잡한 시나리오에서는 계획 수립·문서 탐색에 시간이 지체되고, Thinking token 비용이 높음
- 이에 Prime Intellect와 Qwen 3.5(35B)의 금융 Q&A 특화 모델을 공동 후학습
- 결과적으로 Ops 4.6보다 정확한 결과와 훨씬 빠른 속도 확보, 실제 제품에 적용(생산 적용됨)

### KV 캐시 “카트리지”로 반복되는 월말 결산 등 대량 문맥을 미리 압축·사전 구성함

- 반복성이 높은 금융 업무(예: 월말 결산, 원장/aging report 조정 등)에 과거 문서를 미리 준비해둘 필요
- 기존에는 에이전트가 모든 컨텍스트를 실시간으로 탐색해야 했으나, “카트리지” 방식으로 미리 압축(20~30배)하여 준비 가능
- 월초에 전문가가 접근하면, 이미 필요한 대부분의 문맥 정보를 갖추고 에이전트가 바로 업무를 시작함
- 카트리지는 후학습에 비해 일관성/적응성 면에서 일반화가 잘 되고, 추가 학습 비용도 낮음
- 장기적으로 Frontier 모델(API 제공 등)이 자체 제공할 가능성 있지만, 사내 노하우가 쌓여 가동 초기부터 이점을 가져감

### 대규모 병렬 에이전트로 자동화된 전사 보안점검과 문제중복 제거, 검증을 이뤄냄

- Ramp Inspect라는 클라우드 에이전트 인프라 사용, 1만 개의 에이전트 병렬로 전사 인프라 펜테스팅 진행
- 각 에이전트 분산작업, LLM 기반으로 발견 이슈 중복 제거 및 Adversarial 재현까지 자동 수행
- 총 7건의 고위험 취약점 발견·패치, 그 중 하나는 Lua 스크립트 이슈로 여러 컴포넌트를 조합해 파악
- 자동화 운영으로 인적 리소스 투입 최소(토큰 비용만 발생)
- 오픈웨이트(Open-weight) 모델을 Frontier 모델 대신 활용시, 비용 1/5 수준으로 유사한 탐지율 확보

### Ramp의 Applied Research는 “비용절감+속도개선”으로 서비스 가치를 직접적으로 높임

- Ramp의 사훈 “고객의 시간과 돈을 아껴준다”에 충실히 AI 기술을 활용
- 모든 연구 프로젝트(특화모델, 캐시, 자동화 등)의 핵심 지향점은 토큰 단가 하락과 지연시간 감소
- 각 사례에서 모델 선택, KV 캐시, 대규모 분산처리 등은 결과적으로 Ramp 사용자/고객의 생산성과 비용효율을 극대화함

### 토큰 사용량 추적과 지능형 라우터 등 연구 성과가 실제 제품에 누적적으로 적용됨

- 토큰 사용 모니터링 제품: 사내 API키별 LLM 사용량, 부서별, 사용자별, 회계 카테고리·세액공제 등까지 세부 분석 가능
- Ramp만의 텍사노미 구축, 의미론적·문맥적 분석으로 LLM 사용 양상 심층 분석
- “Ramp Router”: 다양한 라우팅 전략(Nvidia Switchyard 등) 개발, AI Task를 가장 적합한 모델에 동적 분배하여 비용·속도 균형
- 미래에는 더 많은 라우팅 전략 출시 예정

### Frontier 모델 API가 연구 성과를 흡수하더라도, 사내 노하우 축적은 빠른 적응력을 보장함

- Frontier 모델 API에서 자동화/카트리지 등 기능이 공식적으로 제공될 경우 Ramp는 사전에 습득한 노하우로 즉시 활용 가능
- 연구성과의 제품 반영 속도와 “런칭 첫날부터 활용” 가능성이 높음

### Ramp Labs 블로그는 금융 특화 LLM 적용 노하우와 후학습 지식 이전 등 다양한 실험 결과를 공유함

- “Portal” 프로젝트: 한 포스트 트레인 모델(Lora 등)에서 추가 학습 결과를 다른 모델(예: Qwen 업그레이드 버전 혹은 전혀 다른 계열)로 지식 이전 가능
- 요렇게 하면 포스트 트레인 비용 감축과 운영 유연성 확보
- 블로그에서는 agentic map/reduce, 토큰 소비 분석, 셀프 모니터링(자동 DataDog 모니터링 및 실시간 최적화) 등 다양한 실험 케이스 논의
- 의미론적 태깅을 통해 LLM 사용 내역을 사용행태 클러스터별로 정리, 실제 토큰 소비와 매칭하여 조직 내 최적화 지원
- 연구 결과 및 추가 사례는 x.com/ramplabs와 발표자 트위터에서 꾸준히 공개

### 실제 사례와 실험 결과는 Ramp의 제품과 운영 방식 변화로 이어지고, 궁극적으로 고객 효익에 기여함

- 특화 금융 Q&A 모델 개발, KV 캐시 활용, 에이전트 스웜(병렬처리) 등 신기법은 모두 실제 서비스(Beam Sheets, Inspect 등)에 적용됨
- 내부·외부 사용자 모두 실제 가치(속도/정확성/비용절감)를 체감할 수 있게 제품에 반영
- 연구 과정을 블로그, 제품, API 등 다양한 채널로 공유 확장하며 스스로의 노하우와 경쟁력 강화
