## *투자자의 우위는 머릿속에 존재한다—Anekha Sokhal, Moshi* 핵심 요약

- 이 영상은 Moshi의 창업자이자 CEO인 아네카 소칼(Annika Sokhal)이 투자자의 '컨텍스트'와 인간 뇌의 강점, 그리고 AI와 결합된 투자 의사결정의 미래를 논의함
- 현재 데이터 양이 기하급수적으로 증가(2025년 기준 175제타바이트)에 따라 투자자와 금융 전문가들은 정보 과부하와 집중력 저하라는 역설에 직면
- 투자자에게 '엣지(Edge)'란 누구보다 먼저 정보를 파악하고, 블라인드스팟과 2~3차 영향까지 인지하며, 확신을 갖고 의사결정해 더 큰 수익을 내는 능력임
- 모든 사람이 동일한 AI모델과 툴을 이용할 수 있게 되면서 차별적 우위는 다운로드되는 기술이 아닌, 투자자 개개인의 머릿속에 있는 경험과 직관(IP)으로 귀결됨
- 기존 금융 기관은 퀀트, 데이터 사이언티스트, 엔지니어 등 전문가 집단이 협업했지만, AI 툴로 그 구조가 API 호출만으로 대체될 수 있다는 인식이 확산
- 실제로 AI 기반 의사결정 자동화는 운영적 문제(보안, 신뢰성, 비용)와 직관 및 책임성 결여 등의 한계를 가짐
- 투자 의사결정과정에서 기계는 데이터 수집·정리에 강점, 인간은 복합적 판단과 확신 제공에 강점 있음—둘의 협업이 이상적
- Moshi는 24/7 작동하는 기관급 퀀트 분석가로, 인간 투자자의 뇌를 강화(steroids)해주기 위해 시장, PDF, 이메일, 구독 등 방대한 데이터를 자동 분석 및 정합성 검증함
- Moshi는 24억(2.4B)개 이상의 데이터 포인트 학습, 4초마다 300개의 새로운 정보 학습 등 기계학습의 스케일 강점을 현실화
- Moshi의 목표는 데이터와 컨텍스트 수집·분석은 기계가, 최종 판단과 확신은 인간이 담당하여 투자 효율성을 35%까지 높이고, "뇌에 데이터를 공급"하는 혁신을 실현하는 것임

## 세부 요약 - 주제별 정리

### 데이터 폭증 시대에 투자자가 직면한 정보 과부하와 집중력 저하

- 2025년 세계는 175제타바이트의 데이터를 생성, 20년 전과 비교해 데이터 양이 기하급수적 증가
- 과거엔 신문, 책, 제한적 인터넷 연결에 기반했으나, 현재는 PDF, 구독 서비스, 팟캐스트, SNS(X, LinkedIn) 등 다양한 정보원에서 데이터가 지속적으로 유입됨
- 데이터 홍수는 정보의 질 향상으로 직결되지 않고, 오히려 모든 투자자가 동일하게 정보에 압도되어 주의력 결핍을 겪음
- 금융 전문가(투자자)는 이러한 데이터와 주의력 간 간극이 커짐에 따라 실질적 결함과 한계를 경험

### 인간 뇌의 에너지 효율성과 추론 능력은 기계보다 압도적으로 우수함

- 인간 뇌는 86억 개 뉴런, 20와트(백열등 수준)의 에너지로 작동하면서도 복잡한 연결과 추론을 수행
- AI 시스템(머신러닝 모델 등)은 인간 뇌의 일부 기능만을 모방하기 위해 전체 발전소 수준의 에너지가 필요
- 어떤 의사결정 지점에 AI를 적용할지, AI와 인간의 역할 분담이 중요함을 강조
- 인간의 뇌가 가장 효율적 추론 엔진이므로 AI는 완전 대체보다는 '보완'에 더 큰 가치가 있음

### 투자자의 '엣지'는 타인보다 앞서 정보를 해석하고, 블라인드스팟과 확신을 확보하는 능력임

- 투자자가 추구하는 3가지 엣지는 "남들보다 먼저 알기", "2~3차 영향(derivatives) 및 블라인드스팟 파악", "확신을 기반으로 한 투자 포지션 확대"
- 기술 평준화(모두가 같은 AI툴, 데이터 사용) 시대에 '엣지'는 더이상 기술 자체로 확립되기 어려움
- 투자 경험, 직관, 수십 년간 현장에서 쌓은 노하우, 동료와의 협업 등 '비공유적' 지식(IP)이 진정한 차별점임

### AI 확산에도 불구하고, 인간 투자자의 직관과 경험은 대체될 수 없음

- AI가 퀀트, 데이터 사이언티스트, 트레이더를 API 호출로 대체할 수 있다는 인식이 있으나 현실은 다름
- 실제 AI 도구를 누구나 쉽게 개발할 수 있지만, 공유시 보안, 신뢰성, 운영 비용(크레딧) 등 실질적 어려움 존재
- 툴의 차별화가 점차 어려워지며, 인간 투자자의 머릿속 경험이 더 중요해짐

### 금융 도구의 진화와 데이터 'Pull'과 'Push'의 구조적 차이

- 금융 AI 도구는 데이터를 끌어오는(Pull), 혹은 데이터를 사용자에게 밀어주는(Push) 두 가지 유형으로 구분됨
- 사용자가 LLM 등 AI모델에 프롬프트를 전달하는 방식은 항상 과거 문맥에 기반해 대화(예: FOMC 일정에 대한 잘못된 답변)
- 반면, Push형 도구는 정보를 홍수처럼 전달하고, 사용자는 이들 정보 속에서 맥락을 파악해야 하는 데이터 엔지니어링 문제를 맞닥뜨림
- 실제 의사결정은 양방향(맥락 전달+신규 정보 제공)이 결합되어야 효과적

### 전통적인 금융기관의 멘토링·학습 문화와 AI 도입 시 미래 세대의 지식 계승 문제

- 기존에는 신입이 트레이더 옆에 앉아 실시간으로 현장 지식을 흡수하는 관행이 주효
- 1인팀(One-person pod) 형태로 AI가 보편화되면, 이러한 컨텍스트와 경험의 계승 구조가 무너질 수 있음
- 금융 현장 지식·경험의 전승이 투자자 생태계의 핵심적 자산임에도, AI 전환의 비용적 리스크로 충분히 고려되지 않고 있음

### 금융 의사결정 자동화에서는 인간 책임성과 에러 관리의 대체 불가능성이 중요함

- 금융 거래(상품 거래, 기업 등)에서는 맞은편에 실제 인간이나 물적 자산이 존재
- 사고 발생 시 책임을 질 수 있는 인간 결정권자가 필요하며, AI 에이전트의 자기 복구적 사과와 달리 책임소재가 명확해야 함
- API 키 유출 등 사소한 에러도 금융에서는 치명적 결과로 확대됨—에이전트 기반 완전 자동화로는 해결 불가

### 데이터 정제·수집에서 기계의 강점, 최종 판단·확신은 인간의 몫이 되어야 함

- 트레이딩 전 데이터 리딩, 정보 수집, 다각도 교차점검, 시장 모니터링 등 일련의 사전작업이 필요
- '진실(Truth)'의 확립, 정보 출처의 신뢰도, 컨텍스트의 정확성 확인이 핵심
- AI는 '그라인드(Grind)'—데이터 수집·정리에 강점 / 인간은 '판단(Judgement)'—최종 결정에 강점
- 역할 분담이 투자 효과 극대화의 열쇠임

### Moshi는 인간 뇌의 한계를 보완하는 24/7 퀀트 분석가로서 작동함

- Moshi는 6개의 결정론적(Deterministic) 에이전트 팀이 기관투자자용으로 설계되어 주식, PDF, 이메일, 전문 구독 등 방대한 시장 데이터를 24/7 모니터링
- 24억 건(2.4B+) 데이터 포인트 학습, 4초마다 300개의 새로운 정보 습득 등 초대규모 맥락 수집 및 처리 능력 구현
- 새로운 컨텍스트의 신뢰성 및 평가(환각/사실 검증), 분석의 추적성(Traceability), 판단 근거 및 가정 표출을 중시
- 최종 투자 결정은 인간 투자자가 내리도록 구조 설계—기계는 최대한 뇌에 필요한 정보와 분석만을 공급

### Moshi 활용으로 투자 효율성이 35% 향상되며, 인간의 직관+머신의 데이터가 결합된 새로운 투자 패러다임을 실현함

- Moshi 도입시 투자자는 반복적인 데이터 작업이 아닌, 높은 확신을 내릴 수 있는 의사결정(Headspace)에 집중 가능
- 트레이더들이 '대화형 LLM'보다는 실질적 데이터와 컨텍스트 제공을 더 원한다는 현장 의견 반영
- 인간의 본능 + 폭넓은 데이터 기반 추론을 결합해 "너 자신이 슈퍼 강화된 상태(You on steroids)"로 기능
- 초대규모 시장 경험(수십 년의 퀀트 지식)이 자동화되어 각 투자자에게 제공됨
- Pull(LLM으로 구식 컨텍스트 전달)에 그치지 않고, Push(새 정보→뇌 자극)로 블라인드스팟·심층정보까지 다각도로 제공
- Weekend툴이 아닌, 기관급 신뢰성과 추적성을 갖춘 인프라 수준의 서비스—최종 책임과 근거 제시 방식 또한 인간 중심으로 설계

### AI가 투자자의 두뇌에서 어느 정도의 엣지(Edge)를 재현할 수 있는지는 미해결 과제로 남아있음

- 인간 뇌에 집약된 '진정한 엣지'의 기계 재현 비율과 잠재력은 아직 누구도 확정적으로 대답하지 못함
- 만약 누군가 이 과제의 해답을 낸다면, 그것은 단순한 제품이 아니라 금융 사고방식 자체의 패러다임 전환이 될 것임
- Moshi팀은 트레이딩 산업 내 주요 플레이어들과 조용히 협력해왔으며, 대중에 최초 공개
- 모든 투자자가 데이터 과학·퀀트팀 없이도 기관급 금융 분석 역량을 누릴 수 있도록 혁신 추구
- 투자 전 Moshi와 먼저 상의하라는 메시지로 강연 마무리
