## *데이터의 현주소 — 션 차이(State of Data — Sean Cai)* 핵심 요약

- 션 차이는 기업 이해관계 없이, 데이터 시장의 실제 동향과 배경, 업계 내부의 현실을 전달하기 위해 강연을 진행함
- 데이터 시장의 규모와 성격이 변화하고 있으며, 10~15억 달러 규모의 전통적 라벨링 시장은 이제 핵심이 아님을 강조
- 데이터 산업은 수직 통합된 거대 기업(예: Remarque, Surge, Scale AI)에서 벗어나, 단계별로 특화된 공급망으로 분화가 진행 중임
- 데이터 품질은 수량과 비례하지 않게 되었으며, 여러 벤더를 활용하는 ‘분산 발주’ 형태가 일반화됨
- 모델 성능 개선은 컴퓨트, 데이터, 인재라는 세 가지 축간 균형에 좌우되는데, 현재 데이터가 가장 저평가·저투자된 요소임
- 기존의 ‘상태 기반 데이터’(ERP 등)에서 ‘프로세스 기반 데이터’(작업 과정, 의사결정 흐름)로 가치 방향이 이동하고 있음
- gpqa처럼 전문가가 인위적으로 만든 ‘조작형(type2)’ 데이터가 주로 팔리고 있으나, 실제로는 실제 업무 흐름(세션 리플레이, 깃허브 등)인 ‘실제형(type1)’ 데이터가 모델 개선에 더 중요
- 시장 검증(Verifier’s Law)에 따라 검증 용이성이 높을수록 AI 적용이 빠른데, 코딩 분야가 3요건 모두 충족하며 가장 먼저 성숙함
- 대다수 벤치마크·평가는 Goodhart’s Law에 따라 조작 우려가 높고, 실제 성능을 제대로 반영하지 못함
- 앞으로 데이터 산업의 지속가치와 혁신은 어플리케이션 레이어 및 실제 리얼월드 파이프라인 구축에 달려 있음을 역설함

## 세부 요약 - 주제별 정리

### 데이터 시장은 수직 통합 시대에서 분화·전문화 시대로 전환되고 있음

- 사람들은 데이터 시장을 2019년 스케일AI처럼 인간 라벨러가 이미지를 손수 가공하는 모습으로 오해하는 경우가 많음
- 과거 Remarque, Surge, Scale AI 등 데이터 기업들이 데이터 수집·정제의 모든 단계를 직접 수행했지만, 시장 미성숙기에만 가능한 방식이었음
- 현재는 엔드투엔드 공급망이 세분화되어, 단계별 전문업체가 분업해 더 나은 품질과 효율을 제공함
- 모델 성능을 정밀하게 높이려면 ‘일반적 데이터’가 아닌 ‘현장 전문가 데이터’가 필요하고, 이런 데이터는 기하급수적으로 비싸짐
- 데이터 품질이 대량 확보로 쉽게 스케일되지 못하므로, 많은 연구소가 데이터 벤더를 20~30개로 분산 발주하는 것이 트렌드

### 데이터 산업의 핵심 가치는 라벨링이 아니라, 수직 시장 전체 노동력에 있음

- 데이터가 백색칼라 혁명의 중심이며, 빅데이터의 잠재 시장(TAM)은 특정 산업군을 넘어 모든 노동(white collar labor)을 대상으로 확대됨
- 산업화된 공급망은 표준화·유통망 확대로 기존 제조업과 유사한 분화 과정을 밟고 있음
- 데이터 공급망에서 전문성, 인력 소싱, 환경 구축, 인센티브 설계, 평가 체계 운용 등 각각 전문 기업이 유망
- 공급망의 영구적 분화에 따라, 과거 거대 벤더 중심 시장에서 다수 소형·전문 기업이 경쟁하는 구조로 변화함

### 모델 성능의 본질적 개선에 있어 데이터 요인이 과소평가되고 있음

- 모델 성능은 ‘컴퓨트(연산 자원), 데이터, 인재’의 3요소로 결정됨
- 션 차이는 이 세 요소의 불균형이 AI 성능 저하, 투자 효율 저하를 초래한다고 주장
- 최근 AI 분야에서는 CapEx(자본지출)가 기하급수로 증가하는 반면, 데이터 투입이 실질적으로 부족해 비효율성이 심화됨
- 일반 모델을 전문적 ‘전문가형 모델’로 승화시키는 데 결정적 역할을 하는 것이 ‘데이터’임을 강조
- 데이터에 대한 투자 및 혁신이 이루어지지 않은 현 상황에서, 데이터는 보완의 기회로 간주됨

### 데이터의 가치 기준이 ‘상태 기반’에서 ‘프로세스 기반’으로 이동하고 있음

- 많은 이가 데이터란 ERP의 로우(최종 산출 결과)라고 착각하지만, 이는 기본적인 프라이버시 보호 대상임
- 현재 가치 있는 데이터는 업무의 ‘과정’, 즉 문제 해결의 단계, reasoning trace, 작업 의사결정 흐름 등 ‘프로세스 기반 데이터’임
- 실제 전문가가 from scratch로 작업을 완성하는 과정과 방법론을 담은 데이터가 AI 숙련도에 결정적임

### 실제형(type1) 데이터와 조작형(type2) 데이터의 구분 및 시장 문제점

- type1(실제형) 데이터: 예시로 Github 커밋, 실제 세션 리플레이 등 실제 업무 환경에서 수집, 비전문가(또는 최소한의 개입)로 캡처
- type2(조작형) 데이터: 도메인 전문가를 고용해, 인위적 예시를 만들어내고 라벨링함
- type2는 모델의 ‘초급 단계’에는 효과적이지만, 고숙련도 달성(20→80% 구간)에는 한계
- 산업 실상: 대부분의 벤더가 type2 데이터를 팔면서도 type1으로 홍보하는 ‘시장 왜곡’ 현상이 만연

### AI 적용의 성과와 검증가능성(Verifier’s Law)의 상관관계 구조

- 제이슨 웨이(Jason Wei)의 ‘Verifier’s Law’: 모델이 특정 업무를 쉽게 학습할수록, 해당 업무의 검증가능성이 높음
- 검증가능성 3축:
    1. 분해 가능성(asymmetry): 업무를 낱개로 검증 가능한 단계로 나누기 쉬운가?
    2. 진실성(veracity): 결과의 정답 여부에 사회적 합의가 존재하는가?
    3. 반복 생성 가능성(proliferation): 충분히 다양한 실제 검증 예시가 반복적으로 생성되는가?
- 코딩은 unit test, 커뮤니티 합의, 무한한 공개 예시로 3요건을 모두 충족 → 첫 AI ‘시장성숙’ 영역이 됨

### 향후 AI 도입이 빨라질 산업군은 검증가능성이 낮아 성숙이 더딤

- 바이오, 보안, 취향, 금융, 헬스케어, 법률 등은 검증가능성·진실성·예시 생성 모두 낮거나 제한적임
- 엔터프라이즈 내부 데이터에만 편재되어 있으므로, 외부 웹2.0 시스템으로 대량 축적되지 않음
- 최근 AI 기업이 슬랙 로그, Jira 로그 등 실제 업무흐름 데이터를 구매하려 하는 이유임
- 코딩→검색→금융→헬스케어/법률→사이버/생명과학→취향(가장 검증 곤란) 순으로 도입 및 AI 성숙이 차례로 진행됨

### 벤치마크 평가 체계의 조작성과 실효성 한계

- 데이터 벤더는 실제 벤치마크를 조작해 시장에 판매(예: Goodhart’s Law—측정치 자체가 목표가 되면 실질적 의미 상실)
- 인위적(type2) 벤치마크는 서로 독립적이고 격리된 문제에만 최적화되어, 연속적·종속적 작업에서는 성능을 반영하지 못함
- benchmark psychosis: 벤치마크 수치에 과도집착하며 시장이 실제 가치와 멀어지는 현상
- 각종 RL 환경/벤더가 제공하는 싱글 리더보드 지표는 단지 한 분포의 무작위 표본에 불과함

### 실제 벤치마크 실험 사례 및 한계 분석

- 션 차이는 벤더 3곳에서 받아온 실제적 금융 업무(ARR 정산, LBO 밸류에이션, 롱숏 페어 트레이드) 3종으로 내부 평가
- Opus 4.8은 오히려 4.7보다 특정 평가기준에서 저조, GPT 5.5와 Opus 4.08은 상반된 강점(연산 vs. 방법론) 보임
- 실제로 다축 평가를 실시해야, 어느 모델이 어떤 방향성으로 개선되었는지를 파악할 수 있음
- RL환경 기업(실세계 평가 자동화)도 단일 지표만으로 실제 모델 개선 여부를 보여줄 수 없음

### 데이터 및 AI의 미래는 실제 워크플로우 파이프라인과 엔터프라이즈 대응력에 달려 있음

- 시장의 다음 application layer가 어디가 될지는 실제 ‘직무 단위 작업’의 3요소(검증 분해성·진실성·반복 생성성)로 가늠 가능
- Anthropic이 1~3월 동안 각각 보안, 바이오 데이터를 집중 구매하자, 2~3개월 뒤에 해당 분야 신규 AI 제품(Metis, Cybor, Claude Bio 등)이 등장함
- 복잡 장기 업무(long horizon)의 정의도 벤더마다 제각각이므로, 연속적 의사결정, 도구 호환성, 실제 장애 대응력 등 다양한 신호로 과업의 성숙도를 체크해야 함
- 반례: 로보틱스 분야는 데이터 취득구조(ego vs teleop vs umi 모드 등)나 시장 전문성이 미흡, 실제론 벤더조차 연구적 난제와 직결

### 어플리케이션 레이어 중심의 데이터 기업 변신과 전략 변화가 가속화되고 있음

- 인프라/파운데이션 모델(예: OpenAI, Anthropic)가 영구적 시장 지배력을 갖는 일은 역사적으로 드문 일임(철도, AWS, 구글 모두 마찬가지)
- 모델별 효율/모달리티가 다르기에 완전한 상호 대체 가능성(fungibility)이 없음
- 데이터 기업은 점차 엔터프라이즈 대상의 서비스형 데이터, RL as a Service, 실세계 데이터 파이프라인 구축 쪽으로 전환
- 파운데이션 모델의 독점 구조가 무너질수록, 실제 가치와 혁신은 ‘실행 가능한 파이프라인’ 및 자체 재훈련 인프라를 갖춘 응용 분야에 집중됨

### 션 차이의 연구 방향 및 영상 결론

- 데이터 구매 및 과업 검증을 외부 벤더에 전적으로 의존 말고, 실제 현실을 반영하는 평가지표와 파이프라인을 자체 구축할 것
- 진정한 ‘차별화 포인트’는 데이터 자체가 아닌, 실제 업무와 연동된 데이터 파이프라인과 끊임없는 재훈련 인프라에 있음
- 션 차이는 여러 실제 엔터프라이즈와 협력해 RL as a Service와 데이터 자산 실질화 사업을 추진 중임을 공개
- 영상 말미, 데이터 시장 및 AI 혁신의 핵심은 실제 업무 환경과 결합된 데이터의 가치 창출임을 강조하며 마무리
