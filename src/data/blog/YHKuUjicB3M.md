## *내 AI 소프트웨어 팩토리는 주간 수백 건의 PR을 배포한다 (이렇게 관리한다)* 핵심 요약

- 영상은 AI 기반 소프트웨어 팩토리 구축과 운영 경험, 자동화/관제 도구(대시보드) 개발 과정을 상세히 소개함
- 시스템 주요 특징: 이슈 티켓이나 릴리스를 입력만 하면 자동 기획→검증→배포까지 전 과정을 수행, 중간에 사람의 의사결정도 유연하게 개입 가능
- 완전 자동화의 한계를 체감하고, 사람의 결정권을 최소화하면서도 최대한 자동화를 구현하는 균형점을 찾아진화해온 과정을 설명함
- 실제 소프트웨어 팩토리 운영에서 주요 주제: 워크플로우 관리, 각 단계별 에이전트 작업 추적, 의사결정 로그/변경 이력, 장애분석, 병렬처리/스케일 아웃 전략, 테스트 케이스 자동화 등
- 팀 공유 AI 어시스턴트 ‘빅터(Victor)’를 활용, 슬랙/팀즈에서 직접 작업 할당 및 상태 질의, 실질 업무 자동화에 배치하는 예시 소개
- 관제대시보드는 공장 전체의 운영·상태·결정 과정을 한눈에 파악할 수 있는 형태로 진화, GitHub, JIRA 등 기존 도구의 한계를 넘어섬
- 데이터는 PostgreSQL과 Neon을 활용해 저장·처리, Neon의 실시간(Real-Time) 기능, 함수(Function)·오브젝트스토리지·AI 게이트웨이 등 신기능을 적극 접목
- 핵심 자동화 엔진인 오픈소스 ‘아르칸(Arcan)’이 다양한 워크플로우를 코드로 구성·추적할 수 있게 해, SDLC 전체를 체계화
- 시스템의 결정/실패/상태 등 상세 로그·과거 이력, 리그레션 테스트 시나리오 등을 기록해 문제 진단·롤백·프로세스 개선을 지원
- 본 프로젝트는 오픈소스화되어 누구나 자체 AI 소프트웨어 팩토리 구축·응용이 가능, “최강 성능”을 원하면 Neon과 연동할 것을 권장
- 영상 전반에서 단계별로 대시보드 UI와 실제 데이터, 각 부분별 기술적 세부 사항, 팀 내부 실무 적용 예시까지 구체적으로 시연·설명함

## 세부 요약 - 주제별 정리

### AI 소프트웨어 팩토리의 완전 자동화는 한계가 있으며 인간과 시스템의 균형 잡힌 협력이 필수임

- 연간 수많은 시간을 AI 소프트웨어 팩토리 구축·개선에 투자해옴
- 초기에는 AI가 PRD(프로덕트 요구사항)만 받아 완전 자동 분할·코딩·검증·머지까지 모두 처리하는 '다크팩토리' 형태를 목표로 했으나, 한계 직면
- 완전히 인간 개입 없는 자동화는 Proof of Concept 단계 정도에만 적합
- 복잡하고 실제 서비스에 적용하기에는 위험요소가 많아, 적당한 수준의 인간 개입과 검증이 필수임을 경험적으로 깨달음
- 현재는 최소한의 의사결정 포인트만 사람에게 할당하고, 나머지는 최대한 자동화하는 ‘소프트웨어 팩토리’로 선회
- 이 균형이 실제 큰 규모에서 운영 가능한 시스템의 핵심임을 강조

### 소프트웨어 팩토리 관리를 위한 대시보드는 운영의 복잡성을 극적으로 줄여줌

- 운영 효율성을 위해 ‘미션 컨트롤’ 대시보드를 직접 설계·개발
- 공장 전체의 진행 상황, 개별 랩(워크플로/기능별 작업), 에이전트별 임무 등을 한눈에 확인할 수 있는 UI 제공
- 각기 다른 여러 팩토리(예시: 2개 팩토리 연결)와 모든 업무의 상태·이력 추적 가능
- 상위 수준의 의사결정 목록, 실시간 현황, 대기 중인 결정(OWNER 탭) 등을 통합 관리
- 기존에는 개별 GitHub 이슈나 PR, 이메일/슬랙 알림 등 파편적으로 체크해야 했던 모든 사항을 대시보드에서 한 번에 모아봄
- 긴밀한 현황 파악, 빠른 장애 대응, 지속적 개선에 핵심적 역할

### 오픈소스 ‘아르칸(Arcan)’은 대규모 AI 코딩 워크플로우의 핵심 동작 엔진임

- 모든 에이전트는 Arcan 워크플로우 기반으로만 운영됨(기본 제공)
- Arcan은 AI 코딩 플로우를 ‘재사용 가능한 워크플로우’로 정의하고, 모든 설계/구현/검증/리뷰 단계를 구조화함
- SDLC(Sofware Development Life Cycle) 전체 흐름을 코드화·이력화
- 로그, 각 단계(에이전트 행동, 툴 호출, 의사결정 등) 모두 DB에 실시간 저장
- Arcan UI에서 각 워크플로우의 로그와 상세 실행 이력 추적 가능
- 동료인 Rasmus와 함께 워크플로우, SDLC 패키지 등을 협업 개발 중

### ‘빅터(Victor)’ AI 어시스턴트는 팀 전체가 실시간으로 업무를 자동화하고 질의·처리할 수 있게 해줌

- 빅터는 슬랙 및 팀즈 플랫폼에서 동작하는 공유형 AI 어시스턴트
- 단순 질문 답변을 넘어서 실제 JIRA/코드 레포 관리, 아젠다 생성, open thread 파악, 테스크 생성 등 실질적인 업무 자동화 지원
- 영상에서는 실제 팀 미팅에서 빅터를 활용해 아젠다 정리→의사결정 기록→JIRA Task 전환→즉각 팀 적용까지 시연
- 이전엔 팀원들이 PR/이슈 업데이트를 받기 위해 수 시간 대기했으나, 빅터 도입만으로 몇 분 이내 처리가능
- 9,800개 이상의 SaaS 및 개발자 도구와 통합 지원
- victor.com 통해 무료 체험(코드: Cole Medine 100) 안내 추가

### 대시보드는 PR, 이슈, 작업 진척 및 장애, 테스트 등 모든 데이터의 실시간 통합 관제 허브 역할을 수행함

- Home/Index 페이지에서 공장 전체 진행, 임무, 인력별 의사결정 포인트, 각 작업 세부 상황을 고도로 집계
- 주요 의사결정 기록(What was tried/tested/changed), 실험 및 개선 사항 이력화 지원
- 소스 컨트롤과 Versioning으로 과거 워크플로우/버전 간 차이점 파악 용이(비교 기능)
- 전체 건전성(scorcard): 워크플로우 실행 횟수, 머지(Labs/PR), 시스템 가동 일수 집계
- 자동 생성된 리그레션 테스트 시나리오와 성공/실패 정보 관리, 피처 단위로 검증
- 각 이슈/PR의 실시간 진행 상황(예: 리뷰, 구현, 배포 단계별 랩 확인)
- 작업 난이도 및 동적 경로 설정(간단 과제는 빨리 처리, 복잡 과제는 세분화 및 검증 추가)

### PostgreSQL과 Neon이 실시간 스트림 데이터·이벤트 처리의 기초 인프라로 활용됨

- 모든 데이터(Logs, 워크플로우 Run, 결정/오류 이력 등)는 PostgreSQL에 저장
- Neon의 Functions 및 Real-Time API를 활용, GitHub 이슈/PR 이벤트가 트리거될 때마나 자동으로 DB에 저장·동기화
- 실시간 SQL 쿼리를 통해 대시보드 UI가 “지금 일어나는” 모든 변화를 즉각 반영 가능 (라이브 데이터 표시)
- Neon Functions 활용: 인증, 오브젝트스토리지, AI 게이트웨이 등을 손쉽게 통합
- Neon Real-Time: 거의 무제한 스케일/복수 워크플로우 실시간 추적·관리가 쉬움

### 실질적 장애/실패 분석과 개선에 필요한 “관찰 가능성(Observability)”을 체계적으로 구축함

- 모든 실행 결과·의사결정·오류로그가 아카이빙되어 문제 진단/원인 분석/퇴행 테스트 등에 사용가능
- 예시: 코드 생성 AI의 레이트 리밋 문제(Claude API), 병렬 랩 실행 중 21건 워크플로 실패 등 발생→ 기록 바탕으로 트러블슈팅 진행
- 버전별 변경점 추적, 특정 시점으로의 롤백/재연(testing rewind/branching)도 자동화
- Neon Functions + Arcan + 대시보드 + 실시간 피드백 연계로 ‘문제→원인→개선’의 선순환 확보

### 기존 GitHub/JIRA 중심의 작업관리는 한계가 명확하며, 자체 대시보드가 업무 효율을 비약적으로 높임

- 과거에는 PR이나 이슈 처리 시 에이전트가 코멘트/멘션, Slack/이메일 등 통해 수동 확인 필요
- 관리자는 repo 알림이나 이메일/슬랙 등 여러 채널을 옮겨다녀야 했음
- 대시보드 도입 후 모든 “내가 관여할 일”이 ONE STOP으로 집약됨
- 이슈/PR/리뷰/결정 트리거, 팀의 현황을 모두 한 UI에서 처리 가능

### 시스템의 다양한 커스텀 워크플로 및 개선 실험이 쉽게 이루어짐

- 랩 워크플로의 각 step·skill·prompt를 실험하며 즉각 효과/결과 추적 가능
- 실험·적용·실패·성공 기록을 의사결정 탭에서 한눈에 확인
- 아이디어 단계에서 바로 워크플로에 적용, 개선 실험이 빠르게 반복됨

### 오픈소스 공유로 누구나 구축·응용이 가능하고, Neon 연동 시 강력한 실시간성·확장성 혜택을 누릴 수 있음

- 소프트웨어 팩토리/대시보드/워크플로우 모두 오픈소스 공개(리포지토리 링크 제공)
- 개인적 서버/리포·기존 인프라로도 활용 가능
- 하지만 최고 성능, 실시간성, 확장성을 원할 땐 Neon을 권장(이유: 데이터 수집/판별/실시간 관리에 최적화)
- 영상 마지막에 오픈소스 활용법, Neon 연동 안내, 별도 리소스·레퍼런스 링크 등 제공

### 본 프로젝트는 AI시대 엔지니어링 자동화·효율화의 실전적 참고사례를 보여주며, 지속적인 개량·확장성이 내재됨

- 현재도 내부적으로 ‘자기 개선하는 루프’로 계속 진화 중임을 언급
- 대시보드 UI와 워크플로우, 인프라, 에이전트(빅터, 아르칸 등) 모두 실무 맞춤형 업그레이드 진행중
- 새로운 기능 추가와 안정화, 다양한 실험/운영 데이터를 빠르게 반영할 수 있는 체계가 구축됨
- 실무 중심·구체적 예시 중심으로 현업에 즉시 적용할 수 있도록 설계됨
