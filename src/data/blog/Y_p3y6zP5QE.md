## *직접 관리하는 클라우드 에이전트 팀 구축하기* 핵심 요약

- 본 영상에서는 Jack Wotherspoon(구글 딥마인드 DevEx 엔지니어)이 클라우드 기반의 "매니지드 에이전트(Managed Agents)" 개념과 구현 방식을 상세히 소개함
- 매니지드 에이전트는 로컬 PC가 아니라 클라우드 샌드박스 환경에서 코딩, 리서치, 파일 입출력, 테스트 실행 등 다양한 작업을 자동화하는 API 단위의 에이전트임
- 사용자는 인프라·보안 세팅·하네스 관리 없이 단일 API 호출로 손쉽게 에이전트 환경을 활용 가능
- DeepMind의 Gemini API 상에서 제공되는 매니지드 에이전트(특히 anti-gravity 하네스 탑재), Interactions API 및 다양한 서버사이드 내장 도구에 대해 설명
- 샌드박스 파일 시스템에 사용자 고유 스킬, GitHub 저장소, Playbook 등 다양한 자산을 마운트 및 재사용 가능
- 환경(environment)과 상호작용(interaction)의 개념을 분리하여, 멀티에이전트 워크플로우, 협업 및 상태 공유가 실현됨
- 보안 설계상, OAuth·API 토큰 등 인증정보가 직접 샌드박스로 들어가지 않고, 별도의 프록시에서 주입되어 추가적인 안전성 확보
- 트리거 기능을 통해 매일 정해진 시점에 에이전트 자동 실행, 분석 결과 통보, 슬랙/지라 등 외부 시스템 연동이 가능함
- 실시간 데모로 금융 데이터 분석, 리포트 생성 등 자동화 워크플로우를 시연. Gemini 4 Argon, Gemini Flash 등 다양한 모델 지원 및 1M 토큰 멀티모달/롱디코드 기능 강조
- 사용자는 AI Studio, Gemini API, 관련 문서, 갤러리 예제를 활용하여 손쉽게 자신만의 매니지드 에이전트를 만들고 앱에 통합 가능


## 세부 요약 - 주제별 정리

### 매니지드 에이전트가 지역 실행 환경을 클라우드로 대체하여 확장성과 편의성을 혁신함

- 매니지드(클라우드) 에이전트란 로컬에서 하네스를 직접 운영하는 대신, 모든 과정을 구글 클라우드 기반 샌드박스에서 실행하는 자동화된 에이전트임
- 코딩, 코드 실행, 리서치, 웹 검색, 테스트 작성·실행·검증 등 복잡한 업무를 클라우드 샌드박스에서 안전하게 처리
- 로컬 PC의 리소스, 브라우저 점유, 세팅 문제(팝업 발생, 스케일 한계 등)에서 벗어나 다양한 유저와의 공유 및 앱 내 통합 가능
- 대규모 사용자나 어플리케이션에 빠르고 쉽게 확장 적용이 가능하며, 하드웨어 및 인프라 관리는 필요 없음

### Gemini API 기반 매니지드 에이전트의 구조와 주요 컴포넌트가 단일 API로 추상화됨

- DeepMind의 매니지드 에이전트는 Gemini API에서 단 하나의 API 호출로 구동 가능
- 샌드박스 환경, anti-gravity 하네스, 서버사이드 내장 도구(코드 실행, 웹검색, 파일 입출력 등)가 자동으로 프로비저닝됨
- Interactions API(신규 에이전트 퍼스트 SDK/클라이언트 라이브러리)는 단순 입출력 모델을 넘어 다단계/복수작업 에이전트 흐름을 지원
- 환경을 원격(remote)으로 세팅하여, 매니지드 에이전트 활용 시 설정값(environment=remote)만 추가하면 됨

### 매니지드 에이전트의 인프라 내부 동작 방식이 파이프라인 형태로 설계됨

- 입력은 Interaction API를 통해 전달되고, Gemini API를 통해 샌드박스와 연결
- Google Search, 파일 시스템 등 서버사이드 내장 도구 사용 가능
- 사용자의 커스텀 MCP 툴(예: SMTP 서버, 외부 API 기능 등)도 추가 확장 가능
- 샌드박스 내 파일 업로드, GitHub 저장소 연결, 에이전트 스킬(agent skills) 마운트 등이 실시간 지원됨

### anti-gravity 하네스와 모델 선택 손쉬운 설정으로 다양한 업무에 최적화됨

- 매니지드 에이전트 하네스는 Google anti-gravity 제품군과 동일한 것 사용, 내장 도구 및 툴콜 최적화 지원
- 모델 파라미터 한 줄로 Gemini 모델 종류(Gemini Flash, Gemini 4 Argon 등) 선택 가능
- Gemini 4 Argon(2024년 발표) 모델은 금융 업무·문서 분석 등 고급 작업에 특화됨
- 모델별 특징: Gemini Flash(빠르고 경량화), Gemini 4 Argon(딥러닝, 분석, 롱디코드 지원)

### Gemini 4 모델의 1M 토큰 롱디코드 및 멀티모달 기능이 대규모 분석에 적합함

- 일반 모델의 최대 출력 토큰(약 64K) 한계를 뛰어넘어 입력+추론+출력 포함 1M 토큰 컨텍스트 윈도우 제공
- 수백 페이지에 달하는 금전적, 수리적, 데이터 분석/예측 업무에서 정보 손실 없이 처리 가능
- 금융, 수학, 멀티모달 트랜스포머 벤치마크에서도 발전된 성능 입증
- 복잡한 reasoning, 대용량 문서 내비게이션, 장문 결과 생성 등에 대응

### Interactions(상호작용)와 Environments(환경) 분리가 멀티에이전트 워크플로우를 용이하게 만듦

- interactions: 한 번의 입력·출력, 대화 히스토리(컨텍스트 window) 상태 정보로 관리
- environments: 샌드박스 파일 시스템 및 자산(코드, 보고서, 이미지 등) 상태로 독립 보관
- 한 environment를 여러 에이전트가 교대로 활용 가능(예: 첫 번째 에이전트 파일 저장 → 두 번째 에이전트가 해당 파일 기반 분석→ 세 번째 에이전트가 리포트 작성)
- 다양한 상호작용 흐름을 ID 기반 전가/직렬화하여 팀 단위 참가도 가능

### 파일 시스템 마운트와 에이전트의 유연한 커스터마이징이 실제 개발·업무에 도움을 줌

- agents.md, GitHub 저장소, 커스텀 스킬 등 다양한 파일/자산을 샌드박스에 업로드, 의사 결정 기반 워크플로우 구현
- 에이전트가 코드 검수, 버그 검사, 분석 등 담당 가능
- agents API(agents.create)로 사용자 맞춤형 에이전트 저장·호출·반복 사용 용이
- 반복적인 업무, 템플릿화된 워크플로우를 클라우드 환경에서 재현가능

### 매니지드 에이전트의 보안 프록시가 인증정보 분리 주입 방식으로 취약점 위험을 차단함

- 모든 인증정보(OAuth 토큰, API Key 등)는 프록시 계층에서만 관리, 샌드박스 내부로는 더미 토큰만 전달
- 에이전트가 임의로 토큰 획득·유출할 수 없어, API 호출 시에만 실제 인증정보가 안전하게 주입됨
- 예: GitHub API 호출 시 프록시가 일치하는 토큰을 삽입, 에이전트 “유출 가능성” 원천 봉쇄
- 외부 서비스 연동 시에도 동일한 방식으로 안전성 유지

### 트리거 및 다양한 자동 실행 수단으로 에이전트의 일정한 반복 실행과 외부 연동 구현

- 트리거(Trigger) 기능으로 특정 시점(예: 매일 8:30 am)에 자동 분석, 이메일/슬랙 전송, 지라 이슈 점검 등 자동화 가능
- Webhook, Slack, Jira 등 외부 시스템과 연동하여 데일리 리포트, 할 일 목록, 알림 제공
- 에이전트별로 “스케줄 실행” 기능을 쉽게 개발자 API에서 설정 가능

### 멀티에이전트 워크플로우로 복잡한 작업 분업 및 프로세스 자동화가 실현됨

- API 호출만으로 복수 매니지드 에이전트가 동시에 혹은 순차적으로 전문업무 수행 가능
- 예제 데모: 첫 번째 에이전트로 고급 리서치(SEC 보고서 → Nvidia 찾아 메트릭 추출), 두 번째(분석 코드 실행), 세 번째(결과종합 리포트) 분업
- 파일 시스템 공유 및 환경ID 전달로 단계별 업무 자동화, 각 에이전트의 핵심역할 분담
- 외부 Google Docs, GitHub, Slack 등과 손쉽게 연결하여 결과물이 실시간 공유됨

### 다양한 실사례 데모와 SDK 활용 가이드로 개발자들이 손쉽게 에이전트 앱을 만들 수 있음

- 데모1: Google Drive 내 회사 영수증들 분석 후 시각화 결과 자동 리포트 생성
- 데모2: AI Studio 갤러리 예제로 증권 티커(예: VOO) 기반 재무분석, PDF 리포트 자동 생성
- Interactions API 활용해 에이전트 단계별 reasoning 추적(trace) 가능
- 사용자 정의 에이전트 저장·반복호출·기존 앱 프론트엔드 연동 등 실전 개발 팁 제공
- AI Studio에서 무료로 시작 가능하며, 상세 공식 문서·예제도 안내됨
