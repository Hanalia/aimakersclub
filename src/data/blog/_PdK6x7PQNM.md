## *데이터 품질은 컴퓨트(연산)의 승수 효과를 일으킨다 — Ari Morcos, DatologyAI* 핵심 요약

- 영상 제목은 "데이터 품질은 컴퓨트(연산)의 승수 효과를 일으킨다"로, Ari Morcos(DatologyAI의 CEO)가 데이터 품질의 중요성을 강조하며 시작함
- 최근 6개월 간 컴퓨트 리소스(H100 등의 하드웨어)가 크게 부족해지고 가격이 40% 이상 급등, 토큰 사용량 폭증으로 API 사용 제한 현상까지 발생함
- 컴퓨트 한계 극복을 위해선 모델이 효과적으로 학습할 수 있도록 **데이터 품질을 극대화하는 것이 최우선**임을 주장
- “데이터 품질 향상을 통한 학습 곡선 가팔라짐” → 동등한 연산 자원에서 성능이 대폭 향상, 또는 같은 성능을 훨씬 적은 연산으로 달성 가능
- DatologyAI는 데이터 정제(Clean), 선별(Curate), 생성(Create), 조합(Compose)의 ‘4C’로 데이터 세트를 개선함
- 데이터 큐레이션만으로도 VLM(비전-언어 모델)에서 14%포인트 오류 감소, 145배 적은 연산으로 Quen 3.54b 성능 근접 등 성과 실증
- 언어별 데이터 다양성, 토큰 효율, 벤치마크 디컨타미네이션 등 큐레이션 과정과 구체 사례(Thomson Reuters, rci 등)를 상세히 제시
- 합성 데이터(리프레이징 중심), 도메인/언어 다양성, 다단계 커리큘럼 등의 과정을 통해 실제 고객 사례에서 수백~2,000만 달러 미만 비용으로 SOTA 모델 개발 가능성 피력
- 고품질 데이터를 반복 제공하는 것이 저품질 대량 데이터보다 훨씬 효과적임을 강조하며, 나아가 데이터 품질 개선이 연산 한계 극복의 핵심임을 결론으로 제시
- 데이터 품질 평가 및 대규모 데이터 스케일링이 앞으로의 중요한 연구/엔지니어링 문제임을 언급하며 발표 마무리

## 세부 요약 - 주제별 정리

### GPU 등 컴퓨트 자원의 부족과 토큰 사용 제한이 현실화됨

- 최근 6개월 사이 AI 모델 훈련 및 추론에 필수적인 GPU(H100 등) 자원 부족이 극심해졌음
- H100 가격이 여러 해 동안 지속된 하락세에서 반전, 지난해 말 최저점 대비 약 40% 급등
- Token 사용량(Thinking tokens 포함)이 폭발적으로 증가, 특히 Reasoning(추론형) 모델은 비추론 모델 대비 8배나 많은 토큰을 사용함
- 향후 1년 내 토큰 사용량이 5배 추가 증가할 것이라는 전망 제시
- 이로 인해 실제로 일부 프론티어 API의 접근 제한이나 사용 중단 우려가 현실로 다가오고 있음
    - 예: Google이 Meta Gemini의 사용량을 추론 자원 부족으로 제한
    - OpenAI가 토큰 사용량을 미래 시점까지 예약 판매(토큰 선물) 실험
- API 접근 제한은 비즈니스 정책이 아닌 순수 컴퓨트 부족에서 기인하며, 1st-party 제품이 우선 적용될 가능성 시사

### 데이터 품질 제고가 컴퓨트 한계 극복의 최선의 방법임이 강조됨

- 컴퓨트가 제한된 상황에서 ‘질 좋은 데이터’ 확보야말로 모델 성능 향상의 가장 효과적인 방법임을 반복해서 주장
- 데이터 품질을 높이면 동일 컴퓨트로도 훨씬 높은 성능, 또는 동일 성능을 적은 자원으로 달성("컴퓨트 승수 효과")
- “최대 신호 획득(maximum signal per token/batch)”을 목표로 데이터 큐레이션 필요
- 각 데이터가 모델에게 높은 한계 정보 이득(marginal information gain)을 줄 수 있도록 설계함
- 데이터 세트의 다변성(Diversity)과 임무(Task) 맞춤형 큐레이션의 중요성 언급
    - 법률모델엔 법률 데이터, 의료 분야엔 의료 데이터 등 ‘범용 최적 데이터셋’은 존재하지 않음

### 데이터 품질 곡선의 가파름이 ‘컴퓨트 승수효과’를 현실로 만듦

- x축에 데이터/컴퓨트/시간/비용 등, y축에 모델 성능이 있는 곡선을 제시
- 데이터 품질이 높아지면 ‘회색 곡선→파란 곡선’으로 변화: 동일 컴퓨트 상에서 더 나은 결과
- 실제로, 큐레이션을 통한 데이터세트 개선만으로 10배 이상의 컴퓨트 투자와 동일한 성능 달성이 가능함을 예시로 들음

### DatologyAI는 4C(Clean, Curate, Create, Compose) 프로세스 체계를 정립함

- Clean(정제): 휴리스틱 필터링, 단문•중복•의미없는 데이터 제거 실시
    - 벤치마크 디컨타미네이션(benchmark decontamination): 사전에 벤치마크 답안 데이터 제거해 오염 방지 및 평가 신뢰도 향상
- Curate(큐레이션): 품질 분류기 등으로 고품질, 다양성, 과제 적합성 확보
    - 중복/유사 의미 데이터 축출(semantic redundancies 감소)
    - 업샘플링/다운샘플링으로 데이터 품질 편향 완화
    - Task distribution matching 등 세부 큐레이션 전략 적용
- Create(생성): 데이터 양이 부족할 경우 합성(Synthetic) 데이터(특히 리프레이징)를 적극 활용
- Compose(조합): 다수 데이터셋의 적합 조합과 세분화된 트레이닝 단계별(최대 3단계 이상) 커리큘럼 설계
    - 연속 커리큘럼(Continuous curricula) 등 선도적 개념 적용

### 데이터 큐레이션만으로도 VLM에서 14%포인트 정확도 향상을 달성함

- VLM(Vision Language Model) 실험에서, MAMMOTH 데이터셋(약 250억 토큰)으로 실험 수행
- 기존 여러 공개 모델(Quen 3 시리즈, InternVL 등)의 performance-compute 곡선(파레토 프론티어) 분석
- 동일 데이터셋에서 큐레이션 도입 시 14%p 이상의 절대 성능 향상 확인(오류율 절감 기준)
- Quen 3.54b 모델에 근접한 성능을 단지 145분의 1의 훈련 컴퓨트로 달성
- 별도의 후처리(post-training) 없이도 큐레이션만으로 강력한 벤치마크 성적 확인

### 데이터 큐레이션은 추론 토큰 수와 효율도 크게 개선할 수 있음을 보임

- 데이터 큐레이션은 결과의 간결성(응답당 토큰 수 감소)에 기여
- 동일 인퍼런스 효율 곡선에서, Quen 3.5 대비 35배 적은 flops로 동일/더 나은 응답 성능 확보 사례 제시

### 데이터 다양성 및 언어 큐레이션은 글로벌/비영어 성능 향상에 결정적 역할을 함

- 영어 이외 데이터의 품질 확보 및 다양성 큐레이션이 세계 각국에서 AI 모델 활용성을 높임
- 실험: 약 8%에 불과한 다국어(비영어) 토큰만으로도 영어 중심 모델과 거의 동등, 8배 적은 컴퓨트로 퀜 3급 성능 달성
- 1조 토큰(영어+비영어)로 훈련한 dense llama류 모델이 17조 토큰으로 훈련한 sparse 모델과 비슷한 scaling law 성과(즉, 컴퓨트 효율 제고)
- 큐레이션된 영어 데이터가 비영어 성능까지 향상시키는 "cross-lingual transfer" 현상 발견, 언어 특성 유사성에 따라 이전효과 달라짐

### 합성(리프레이징) 데이터는 품질 높으면 모델 성능 폭증시키는 핵심 전략임

- 합성 데이터 생성은 단순 복제, 샘플링이 아니라 고품질 문서의 다채로운 rephrasing에 초점
- 예시: 기업 인수 관련 문서를 수백 가지 템플릿(예/아니오 문답 등)으로 변환
- 리프레이징 모델은 단순 변환만 해도, 실제 학습 대상 모델은 이 다양한 표현을 통해 높은 학습 효과(모델 캡턴스 방지, 다양성 확장)
- 랜덤 데이터 리프레이징의 한계 → 반드시 큐레이션된 고품질 데이터 우선 리프레이징해야 성능 개선 효과가 큼
- 다른 공개 합성 코퍼스와 비교 시, 학습 속도와 최종 성능 모두 우수

### Thomson Reuters 사례: 법률 특화 모델에서 데이터 큐레이션과 중간 학습의 결합 효과가 입증됨

- Thomson Reuters와의 협업에서 고품질 법률 데이터와 공개 데이터를 결합, 중간(middle) 학습(med-training) 실시
- 1000억 토큰 미드트레이닝(전체 pre-training의 1% 미만)만으로도 Legalbench 평가에서 법률 성능 5%p 상승
- Catastrophic forgetting(일반 성능 저하) 없이 법률 및 전체 성능 동시 향상
- 접목 방식: pre-training 분포의 대표성을 갖춘 데이터에 법률 특화 일부만 삽입, 데이터 설계로 성능 하락 방지
- 포스트트레이닝만 적용 대비, 미드트레인 적용 모델에선 추가 향상 효과가 3배에 달함
- 동일한 포스트트레이닝 데이터/방식이어도, 미드트레인으로 사전 특화된 모델이 훨씬 우수한 결과 기록

### RCI 사례: 퍼블릭 데이터 기반, 2,000만 달러 이하로 SOTA 수준 LLM 제작 성공

- RCI(Robusta Cognition Intelligence)는 2023년 중반부터 Datology와 협력해 완전 공개 모델(pre-training lead: Verun) 훈련
- 17조 토큰, 공개 데이터만 활용하여, GLM5, Kimmy 등 프론티어 모델과 상당수 과제에서 동등 또는 우위 성능 달성
- Claude 대비 일부 과제에서는 성능 상회
- R&D, 인건비, 컴퓨트 포함 전체 비용이 2,000만 달러 미만(수 차례 반복 실험·모델 포함)
- 좁은 도메인 특화 모델이라면 high 6 figures(수백만 달러 내외)로 강력한 모델 훈련 가능성 시사

### 데이터 품질 반복 제공이 대량 저품질 데이터보다 훨씬 가치 있음이 재확인됨

- 무작정 더 많은 저품질 데이터를 투입하는 신화 반박
- 적정 한계 내에서는 고품질 데이터를 여러 번 보여주는 것이 저품질 대량 공급보다 모델 효율 및 성능에 더 효과적임을 강조

### 데이터 평가 및 초대형 데이터 스케일링이 향후 연구·엔지니어링 최대 과제임

- 데이터 품질을 다양한 평가축에서 점수화·정량화하는 기술이 미래의 핵심 연구문제임
- 페타바이트 규모의 대용량 데이터에 품질 평가/큐레이션 기법을 실질적으로 적용하는 대규모 엔지니어링 필요
- 데이터 관련 테크의 발전이 AI 모델 최적화에서 점점 더 큰 중요성과 leverage를 얻게 될 것임

### 결론 및 채용 안내로 발표를 마침

- 데이터 품질이야말로 현재 과소평가된 ‘컴퓨트 승수’이자, compute 제약 극복의 핵심임을 다시 강조
- DatologyAI에서 데이터 품질과 커스터마이즈 모델에 관심있는 인재 채용중임을 알리며 발표 종료
